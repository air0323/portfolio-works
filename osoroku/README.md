# 怖録 -Osoroku- ファンサイト

## ファイル構成

```
favicon.ico    ファビコン（64×64）
index.html     トップページ（KV / 予告 / 作品概要 / ギャラリー / 配信について / ゲーム情報 / お知らせ / お問合せ導線）
contact.html   お問合せフォーム
images/        サイトで使用している画像（WebP）
```

CSS・JavaScriptは各HTML内に記述しています。フォントはGoogle Fontsから読み込みます
（しっぽり明朝 / Noto Serif JP / Barlow Condensed）。

## 公開前に対応が必要な箇所

1. 予告映像：index.html の予告ボタンは、映像の代わりに確認用の画面を表示します。
   公式YouTubeのURLが決まったら、リンクか埋め込みに差し替えてください。
2. お問合せフォーム：contact.html はデモで、送信しても届きません。
   送信先（メールアドレスやフォームサービス）を設定してください。

## 異変（サイト内の隠し要素）

・作品概要の見出し「-縺翫◎繧阪￥-」（文字化け）→ クリックで「-Osoroku-」に戻る
・配信について：セクションが見えている間、手形が画面いっぱいに増えていく → どれか1つをクリックで消える
・ゲーム情報「プレイ人数 0人」→ クリックで「1人」に変わる
見つけた異変は、閲覧者のブラウザ（localStorage）に保存されます。
