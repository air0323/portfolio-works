03

クリエイティブ制作

個人制作Logo / Key Visual / Banner / Flyer / Package

誰に、何を感じてほしいか。
そこから形を決める。

職業訓練で制作したロゴ、キービジュアル、フライヤー、パッケージを紹介します。ターゲットや伝えたい価値を明確にし、ブランドの世界観と使用場面に合わせて、配色・モチーフ・レイアウトを設計しました。※いずれも架空のブランド・イベントを想定した制作です（広告内の日付や「日本初上陸」などの表記も設定上のものです）。

01

時を刻む、身に着ける芸術。

Key Visual / Logošwt（高級時計）

Logoロゴ

古代エジプト語で「影」を意味する言葉から名付けたšwt。日時計に着想を得て、円形の造形に文字盤を、V字のラインに光によって生まれる影と時計の針を重ねました。ネイビーとゴールドで、歴史性と品格を表現しています。

Bannerバナー

ポップアップストアの告知を想定したバナー。革を思わせる背景の質感と落ち着いた配色で高級感を演出し、開催情報は明るい文字色で視認性を確保しました。

Targetターゲット

価格や機能に加え、造形美やブランドの背景にも価値を感じる30〜50代。上質で長く愛用できる時計を求める人をターゲットとしています。

02

香りとの出会いを、視覚から。

Key Visual / LogoKAGUWA（香水）

Logoロゴ

「馨しい」という言葉に由来するブランド名。文字上部の曲線で香りが風に乗って広がる様子を、伸ばしたKのラインで香りの余韻を表現しました。

Bannerバナー

商品とブランドロゴの間に余白を設け、視覚的なバランスと情報の読み取りやすさを意識しました。オレンジブラウンやアイボリーを基調に、大理石を思わせる質感を加え、上品でやわらかな世界観を表現しています。

Targetターゲット

美容や香水への関心が高い30〜50代女性。季節や気分に合わせて香りを選び、自分らしさを表現することを楽しむ層を想定しています。

03

家具の魅力を、暮らしの風景へ。

Key Visual / LogoCoral（家具）

Logoロゴ

ブランド名の由来でもある珊瑚をモチーフに、枝分かれする造形で、家族とともに受け継がれる暮らしを表現。コーラルオレンジを採用し、温かみと親しみやすさを持たせました。

Bannerバナー

商品単体の魅力と、実際の住空間での使用イメージを同時に伝えるため、商品とダイニングの写真を組み合わせました。グレージュを基調に、ゴールドと円形のグラフィックを加え、落ち着きとやわらかさを表現しています。

Targetターゲット

デザイン性や品質、長く使えることを重視する30〜50代。家族との暮らしを心地よく整え、自分らしい住空間をつくりたい人たちに向けたブランドです。

04

「行ってみたい」をつくるデザイン

Flyer / Posterさくらフェスタ／タンブラー展

さくらフェスタ

Conceptコンセプト

表面は春らしい配色とイラストでイベントの楽しさを伝え、裏面には「撮る・食べる・歩く」の3つの体験と、エリアマップ・アクセス情報を集約。来場前の期待感と、当日の回遊しやすさを意識した構成としました。

Targetターゲット

桜や自然、カフェ巡り、写真撮影が好きな20〜30代女性が中心。友人や恋人と出かけ、春ならではの体験や思い出づくりを楽しみたい人を対象としています。

タンブラー展

Conceptコンセプト

「お気に入りの一点に出会う」をテーマに、会場で実物のサイズ感や質感を確かめられる体験を訴求。淡い配色と親しみやすいイラストを用い、雑貨に関心のあるターゲットに向けて、気軽に足を運びたくなるデザインを目指しました。

Targetターゲット

雑貨やカフェ巡り、SNSで新しいアイテムを探すことが好きな20〜30代女性。実用性に加え、デザインや日常で使うときの気分も大切にする人をイメージしました。

05

店頭で目を引く、飲茶パッケージ

Logo / Package蓮飯店（飲茶）

Logoロゴ

ブランド名を象徴する蓮の花を中心に、円形のフレームと笹のモチーフを組み合わせました。赤と黄色を基調に、伝統的な中華の華やかさと親しみやすさを表現しています。

Conceptコンセプト

中華・飲茶カテゴリーに多い赤を基調としながら、桃型の窓やパンダ、点心の総柄で親しみやすさを加えました。店頭での視認性とブランドの記憶に残ることを意識し、飲茶を楽しむ時間が伝わるパッケージを目指しました。

Targetターゲット

点心や中華を好み、パッケージのかわいらしさにも惹かれる20〜40代。家族や友人との食事、ちょっとした手土産として気軽に楽しみたい層を中心に設定しています。

06

贈りたくなる、蜂蜜のギフトBOX

Logo / Package蜂蜜のギフトBOX

Logoロゴ

蜂の身体の曲線に沿って文字を配置し、モチーフとタイポグラフィを一体化。ゴールドの配色で、ギフト商品としての上質さを表現しました。

Conceptコンセプト

蜂の巣を思わせる六角形の幾何学模様を、ダークブラウンとゴールドで表現。箱を組み立てた際に模様が側面をまたいでつながるよう設計し、ギフトとしての特別感を演出しました。

Targetターゲット

贈り物の品質やパッケージの美しさを重視する30〜50代。手土産や季節の贈り物など、大切な人への特別なギフトを探している人に向けて制作しました。
